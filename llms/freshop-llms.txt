# Freshop

> Freshop is an eCommerce platform purpose-built for grocery and specialty retail, now part of NCR Voyix. It powers branded online shopping, order fulfillment, pickup, and delivery for independent and regional grocers. A live REST API at api.freshop.com serves store and product data to Freshop-powered storefronts and mobile apps, authenticated with an application key (`app_key`) query parameter.

## API
- [Freshop API (base)](https://api.freshop.com): REST API, numeric path versioning (/1/, /2/), app_key query-parameter auth. Resources include stores and products.
